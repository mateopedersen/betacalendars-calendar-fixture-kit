# Changelog

## 0.1.0

- Add strongly typed `YearMonth` and invariant parsing/formatting.
- Generate natural and six-week month grids with explicit adjacent-cell policies.
- Add date-free blank layout fixtures, year-boundary and leap-year fixtures.
- Validate dates, weekday alignment, month relations, grid coordinates, and dimensions with structured diagnostics.
- Compare fixtures with structured differences and stable text output.
- Add JSON snapshot helpers and explicit `TimeProvider` integration.
